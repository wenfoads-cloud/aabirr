# أعبر

سيرفر واحد بسيط (Node.js فقط، بدون مكتبات): يعرض الصفحة، ويحفظ البيانات في SQLite، والصور والأصوات في مجلد `data/`.

## التشغيل
```
node server.js
```
ثم افتحي http://localhost:3000 (يلزم Node 22.13 أو أحدث).
أول تشغيل ينشئ المعلمات بكلمات السر التجريبية: t1 أسماء = 1111، t2 لطيفة = 2222، t3 وئام = 3333.

## تغيير كلمة سر
```
node server.js set-password t2 كلمة_جديدة
```
(تُحفظ مشفّرة. t1 أسماء، t2 لطيفة، t3 وئام)

## على سيرفر حقيقي
شغّليه على أي جهاز/سيرفر فيه Node، وخلّي مجلد `data/` محفوظًا (هو كل بيانات الموقع، خذي منه نسخة احتياطية).
المنفذ من المتغير `PORT`، ومكان البيانات من `DATA_DIR`. للـ HTTPS ضعي أمامه Caddy أو nginx.

ضعي `logo.jpg` داخل مجلد `public/`.
